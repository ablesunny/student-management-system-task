# Student Management System

React practical task implementation.

## 👨‍💻 Author & Proof of Work
Hi, I'm **Able Sunny**, and I coded this project entirely from scratch. I built this to put my React skills into practice, with a major focus on managing state, prop drilling, and writing custom form validation manually rather than relying on a backend database or external APIs.

## Requirements covered
- Functional React components: Navbar, StudentForm, StudentList, StudentCard
- useState for students, form values and search
- useRef for automatic Name input focus
- Props between parent/child components
- Controlled form inputs
- map() for student cards
- filter() for searching and deleting
- Add, edit/update and delete
- Validation: name, age, email, course, age >= 18
- Live search by name, email and course
- No database or external API
